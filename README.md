# 🚀 Modern Landing Page

A modern, clean, and responsive landing page built using **HTML and CSS**.  
This project was created as a beginner-friendly frontend development task to practice webpage structure, styling, layouts, and responsive design.

## ✨ Features

- 📱 Responsive design for different screen sizes
- 🧭 Clean navigation bar
- 🎯 Hero section with call-to-action buttons
- 📊 Business statistics section
- 🖼️ Professional image section
- 💳 Floating information card
- 🏷️ Brand/trusted-by section
- 🎨 Modern typography and color scheme
- 📐 Responsive layout using CSS Media Queries

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
